# ISPConfig HERITAGE 1.0.6

## Deutsch

HERITAGE 1.0.6 führt ein einheitliches mobiles Datensatzkarten-System für
Kunden, Webseiten, E-Mail, DNS, Support und System ein. Technische IDs werden
nicht mehr als eigene Hauptinformation gezeigt. Ihr Bearbeitungsziel wird auf
den fachlich wichtigsten Wert übertragen.

Primärwert, Status und Aktionen besitzen nun in jedem Modul dieselbe visuelle
Rolle. Mittlere Smartphone-Breiten nutzen kompakte zweispaltige Details,
während schmale Geräte weiterhin vollständige einspaltige Karten erhalten.

## English

HERITAGE 1.0.6 introduces one responsive record-card system for clients,
sites, mail, DNS, support and system. Technical IDs no longer appear as the
main information; their edit target is promoted to the most relevant business
value.

Primary values, status fields and actions now have the same visual role across
modules. Medium phone widths use compact two-column details while narrow
devices retain complete single-column cards.
