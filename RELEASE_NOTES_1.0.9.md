# ISPConfig HERITAGE 1.0.9

HERITAGE 1.0.9 completes the interaction-feedback layer for ISPConfig 3.3.1p1.
Dialogs, confirmations, notifications and runtime feedback now use one
accessible hierarchy across desktop and mobile layouts.

## Highlights

- semantic dialog tone, description and action-group contracts;
- stable primary, secondary and destructive action classification;
- predictable safe-first desktop and mobile action order;
- severity-aware feedback regions and live announcements;
- pause-aware lifetime indicators for temporary feedback;
- restrained motion with reduced-motion support.

The release remains theme-only. Confirmations, action URLs, submitted data,
permissions and ISPConfig handlers are unchanged.
