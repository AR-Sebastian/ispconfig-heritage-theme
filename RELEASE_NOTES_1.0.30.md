# ISPConfig HERITAGE 1.0.30

HERITAGE 1.0.30 completes the specialty-surface V1 contract for system
configuration, the retained Extension Installer, monitoring data and monitoring
logs.

Dynamic navigation no longer leaves form-specific layout profiles on monitoring
pages. Native ISPConfig panels and operational logs receive stable theme-owned
semantics, while long headings remain contained at compact intermediate widths.

The release was validated on five real ISPConfig surfaces across six viewport
classes and both colour schemes (60 specialty states). A representative
application matrix adds 104 desktop/mobile states across 26 surfaces. The full
release gate also verifies reproducible bundles, package contents, checksums,
offline tamper detection, installation, upgrade and rollback.

This remains a theme-only release. It does not change ISPConfig core behaviour,
database operations or managed server services.
