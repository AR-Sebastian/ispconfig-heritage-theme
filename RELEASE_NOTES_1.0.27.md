# ISPConfig HERITAGE 1.0.27

HERITAGE 1.0.27 extends table acceptance to databases, FTP, cronjobs, mailboxes,
support, servers and remote users. Historical XMPP and vServer columns remain
outside every responsive presentation. The matrix protects 156 runtime states.

The release is presentation-only and does not change ISPConfig controllers,
permissions, stored values or managed server operations.
