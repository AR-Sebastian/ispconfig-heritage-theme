# ISPConfig HERITAGE 1.0.11

HERITAGE 1.0.11 closes the stable V1 acceptance contract. Login and authenticated
shells now load the same runtime cache generation, eliminating stale login assets
after an upgrade.

The release was built from 318 signed package files. ZIP and TAR.GZ parity,
checksums, offline verification, atomic upgrade, backup, rollback and installation
permissions passed. The installed Ubuntu 24.04 Apache preview returned HTTP 200.

The release remains theme-only and targets ISPConfig 3.3.1p1.
