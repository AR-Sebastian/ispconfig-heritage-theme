# ISPConfig HERITAGE 1.0.31

HERITAGE 1.0.31 completes the Tools and Admin V1 contract. Resynchronization,
ISPConfig import, personal settings, users, additional PHP versions, firewall
and IP addresses now expose consistent semantic workspaces.

Dynamic navigation also clears stale table state before rendering a non-table
view. This prevents personal settings and other forms from inheriting invisible
layout state from a previously opened Admin list.

Seven real ISPConfig surfaces were verified across six viewport classes and both
colour schemes, covering 84 browser states. The complete release gate additionally
verifies reproducible bundles, package identity, checksums, offline tamper
detection, installation, upgrade and rollback.

The release remains theme-only and does not replace ISPConfig controllers,
permissions, database operations or managed server actions.
