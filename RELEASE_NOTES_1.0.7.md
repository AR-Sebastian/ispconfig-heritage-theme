# ISPConfig HERITAGE 1.0.7

## Deutsch

HERITAGE 1.0.7 vereinheitlicht die vollständige Seitenkomposition. Titel,
Statusinformationen, Primäraktionen, Meldungen und leere Zustände besitzen nun
in allen unterstützten Modulen dieselbe Hierarchie.

Auf schmalen Geräten bleiben Seitentitel linksbündig, Aktionsgruppen nutzen die
verfügbare Breite und Meldungen behalten unabhängig vom Modul ihre erkennbare
Schwere. Lade-, Leer- und Fehlerzustände teilen eine ruhige, zentrierte Fläche.

## English

HERITAGE 1.0.7 unifies the complete page composition. Titles, status metadata,
primary actions, notices and empty states now share the same hierarchy across
all supported modules.

On narrow devices page titles remain left aligned, action groups use the
available width and messages retain clear severity across modules. Loading,
empty and error states share one calm centered workspace.
