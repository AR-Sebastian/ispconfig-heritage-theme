# ISPConfig HERITAGE 1.0.1

## Deutsch

HERITAGE 1.0.1 ist ein fokussiertes Dashboard- und Distributionsupdate. Die
Übersicht reserviert keine leere Spalte mehr für eine dort nicht vorhandene
Kontextnavigation. Der verfügbare Platz wird für ein ruhigeres, dichteres
Dashboard mit vier kompakten Modul-Widgets pro Desktopzeile genutzt.

Weitere Verbesserungen:

- direkte, prüfbare Installation des signierten Release-Archivs;
- deutsch- und englischsprachige Rückfall- und Fehlerhilfe;
- strukturierter Fehlerbericht für reproduzierbare Rückmeldungen;
- professionellere Repository- und Release-Navigation.

Die Kontextnavigation aller fachlichen Module bleibt unverändert erhalten und
wird beim Verlassen des Dashboards automatisch wieder eingeblendet.

## English

HERITAGE 1.0.1 is a focused dashboard and distribution update. The overview no
longer reserves an empty column for contextual navigation. It uses the reclaimed
space for a calmer, denser dashboard with four compact module widgets per
desktop row.

The release also adds verifiable archive installation instructions, bilingual
recovery guidance and a structured issue-reporting path. Contextual navigation
on module pages remains unchanged and returns automatically after leaving the
dashboard.
