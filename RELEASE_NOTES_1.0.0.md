# ISPConfig HERITAGE 1.0.0

The first stable HERITAGE release provides a standalone premium interface for
ISPConfig 3.3.1p1 while preserving ISPConfig's permissions, routes, APIs and
server-side provisioning.

Key points:

- responsive light and dark presentation;
- horizontal primary module navigation with contextual secondary navigation;
- unified dashboard, tables, filters, forms, dialogs and feedback;
- administrator, reseller, client and mail-user validation;
- Ubuntu 22.04/24.04 and Debian 12/13 with Apache and Nginx;
- reproducible ZIP and TAR.GZ downloads with SHA-256 checksums;
- atomic installation, managed backup and rollback.

Keep ISPConfig's original `default` theme installed as the recovery path.
