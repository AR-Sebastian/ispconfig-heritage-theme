# ISPConfig HERITAGE 1.0.4

## Deutsch

HERITAGE 1.0.4 verbessert lange Eingabemasken. Vom Server ausdrücklich als
fehlerhaft markierte Felder werden oben im Formular zusammengefasst. Bei
mehrseitigen Masken zeigt jeder Tab seine Fehleranzahl an.

Ein Klick auf die Zusammenfassung öffnet bei Bedarf den richtigen Tab, führt
zum ersten betroffenen Feld und setzt dort den Tastaturfokus. Die bestehende
ISPConfig-Validierung, Formularübertragung und Rechteprüfung bleiben vollständig
unverändert.

## English

HERITAGE 1.0.4 improves long data-entry forms. Fields explicitly marked invalid
by the server are summarized at the top of the form, while multi-tab forms show
an error count on each affected tab.

Selecting the summary reveals the relevant tab when needed, scrolls to the
first affected field and moves keyboard focus there. Existing ISPConfig
validation, submission and permission behaviour remain unchanged.
