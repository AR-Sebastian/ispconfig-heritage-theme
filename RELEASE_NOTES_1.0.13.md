# ISPConfig HERITAGE 1.0.13

HERITAGE 1.0.13 establishes one accessibility authority across login and the
authenticated application. Increased contrast, forced system colours, reduced
motion and reduced transparency retain clear focus, navigation and control states.

Active navigation no longer depends on colour alone in forced-colour mode, coarse
pointer controls retain a 44-pixel target, and both shells load the same authority.

The release remains theme-only and targets ISPConfig 3.3.1p1.
