# ISPConfig HERITAGE 1.0.12

HERITAGE 1.0.12 closes language parity and live installation delivery for the
stable V1 line. German and English theme-owned labels are checked as pairs, and
dynamically loaded module fragments retain localization.

All 66 assets referenced by the login and authenticated shells returned HTTP 200
with non-empty content on the installed Ubuntu 24.04 Apache preview. The exact
installed manifest and login route were verified after atomic package installation.

The release remains theme-only and targets ISPConfig 3.3.1p1.
