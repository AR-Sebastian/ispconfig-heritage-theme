# ISPConfig HERITAGE 1.0.33

HERITAGE 1.0.33 extends its compact state system to the five ISPConfig server
capabilities E-mail, Web, DNS, file and database, and to SMTP, delivery, IMAP
and POP3 states in mailbox lists.

Enabled services use a calm success semantic. Enabled disable-flags use a
warning semantic instead, preventing a disabled protocol from looking healthy.
Every symbol retains the full localized column name and value for assistive
technology and tooltips.

Server and mailbox tables were verified with real data on desktop, at the
721-pixel navigation boundary and on mobile in Light and Dark. The release
remains theme-only and changes no ISPConfig data, permissions or server actions.
