# ISPConfig HERITAGE 1.0.8

HERITAGE 1.0.8 completes the shared form-system layer for ISPConfig 3.3.1p1.
Compact settings, long multi-tab editors and mobile forms now use the same
section, field, validation and action hierarchy.

## Highlights

- semantic form, section, field and action-bar contracts;
- accessible relationships between labels, controls, help and errors;
- explicit required, invalid and disabled field states;
- predictable primary, secondary and destructive action order;
- density-aware composition for compact and long forms;
- mobile-first full-width controls and actions.

The release remains theme-only. Field names, submitted values, routes,
permissions, validation rules and ISPConfig handlers are unchanged.
