# ISPConfig HERITAGE 1.0.26

HERITAGE 1.0.26 unifies customer, website, mail and DNS list geometry. Action
columns remain aligned, percentage widths no longer distort current tables,
mobile identities remain available and multi-create toolbars expose a clear
primary and secondary hierarchy.

The release is presentation-only and does not change ISPConfig controllers,
permissions, stored values or managed server operations.
